# =============================================================================
# QuickCart Intent Pipeline — Requirements
# Python 3.10+   |   4-core / 15 GB ceiling
# =============================================================================
#
# LIBRARY RATIONALE
# -----------------
# torch ≥ 2.1
#   Core DL framework. Required for model training, InfoNCE + CE joint loss,
#   and the checkpoint (.pt) save/load cycle. NOT used at production inference
#   (ONNX Runtime replaces it there), so the RAM cost is paid only during
#   training.
#
# transformers ≥ 4.38
#   Provides the BGE-small-en-v1.5 AutoModel and AutoTokenizer. We use the raw
#   HuggingFace model (not the sentence-transformers wrapper) so we can attach
#   a custom linear classification head and export the entire graph to ONNX in
#   one pass.
#
# sentence-transformers ≥ 2.7
#   Used ONLY for the optional cross-encoder reranker at inference time
#   (cross-encoder/ms-marco-MiniLM-L-6-v2). The bi-encoder path does not use
#   this library at all — ONNX Runtime handles that.
#
# cleanlab ≥ 2.6
#   Implements Confident Learning (Northcutt et al., 2021) for silver-label
#   noise detection. Uses cross-validated out-of-fold predicted probabilities
#   to identify and remove mislabelled training rows without requiring human
#   re-annotation.
#
# scikit-learn ≥ 1.4
#   Multiple roles:
#     - LedoitWolf covariance estimator → stable Mahalanobis parameters
#     - StratifiedKFold for Cleanlab cross-validation
#     - classification_report, confusion_matrix for dev evaluation
#     - CalibrationDisplay / brier_score_loss for ECE computation
#
# onnx ≥ 1.16
#   The ONNX graph representation. Required to call torch.onnx.export and to
#   verify the exported graph before runtime use.
#
# onnxruntime ≥ 1.18
#   The CPU-only ONNX Runtime. Replaces PyTorch at inference, reducing per-
#   sample latency from ~40 ms to ~8 ms on 4 cores via kernel fusion and
#   operator-level parallelism.
#
# pandas ≥ 2.1
#   CSV I/O for train/dev/test data, results tables, and submission file.
#
# numpy ≥ 1.26
#   Array math throughout — embedding storage, batch construction, Mahalanobis
#   distance computation.
#
# scipy ≥ 1.12
#   scipy.optimize.minimize_scalar for temperature-scaling T* optimisation via
#   NLL minimisation.
#
# tqdm ≥ 4.66
#   Training loop and batch-inference progress bars.
#
# matplotlib ≥ 3.8
#   Confusion matrix heatmap, ECE reliability diagram, latency histogram.
#
# seaborn ≥ 0.13
#   Nicer confusion matrix styling on top of matplotlib.
#
# accelerate ≥ 0.27
#   HuggingFace Accelerate for seamless CPU/GPU device placement during
#   training without code branching.
#
# =============================================================================
